# E-Commerce SQL Analytics

## 📌 Project Overview

This project focuses on analyzing an e-commerce database using MySQL.

The project covers customer, order, product, payment and order-item data and uses SQL to answer business-related questions and generate actionable insights.

## 🗂️ Database Structure

The database contains five main tables:

- `customers` — Customer information
- `products` — Product details
- `orders` — Order information
- `order_items` — Products and quantities included in orders
- `payments` — Payment details and payment status
